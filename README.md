# ระบบติดตามผลการเรียนส่วนตัว (Study Tracker)

เว็บแอปติดตามผลการเรียนส่วนตัว รองรับ 2 หลักสูตรควบคู่กัน เริ่มต้นภาคเรียนแรก **2/68**:
1. **สทก.ทางไกล ม.ปลาย (76 หน่วยกิต)** — วิชาบังคับ 5 สาระ (44 นก.) + วิชาเลือก (32 นก. เพิ่ม/แก้ไขได้อิสระ) + กพช. 200 ชม. + คุณธรรม + N-NET
2. **Pre-degree ม.รามคำแหง คณะมนุษยศาสตร์ (132 หน่วยกิต — ระเบียบการ พ.ศ. 2568)**
   - หมวดวิชาศึกษาทั่วไป (30 นก.)
   - หมวดวิชาเอกภาษาญี่ปุ่น: เอกบังคับ 51 นก. (17 วิชา) + เอกเลือก 27 นก. (9 วิชา พร้อมระบบเตือนหากเลือกซ้ำ)
   - หมวดวิชาโทจิตวิทยา PSY (18 นก. / 6 วิชา)
   - หมวดวิชาเลือกเสรี (6 นก. / 2 วิชา)
3. **แสดงผลแยกตามภาคเรียน (เริ่ม 2/68)** พร้อมคำนวณหน่วยกิต, **GPA ประจำเทอม** และ **GPAX สะสม**

## วิธีตั้งค่า Supabase ให้ "ข้อมูลไม่หาย + ล็อกใช้ได้คนเดียว"

> ถึงแม้โค้ดหน้าเว็บจะอยู่บน GitHub Pages แต่ **ข้อมูลผลการเรียนทั้งหมดจะถูกเก็บแยกไว้ใน Supabase** หลังระบบ Login + Row Level Security (RLS) ทำให้คนอื่นที่เปิดลิงก์เว็บนี้เข้ามาจะเห็นแค่หน้าล็อกอินและไม่สามารถดูหรือแก้ไขข้อมูลใด ๆ ได้

### ขั้นที่ 1: สร้างโปรเจกต์ Supabase (ฟรี)
1. เข้า [https://supabase.com](https://supabase.com) แล้วสมัคร/ล็อกอินด้วย GitHub
2. กด **New Project** ตั้งชื่อโปรเจกต์, รหัสผ่าน Database และเลือก Region เป็น **Singapore**

### ขั้นที่ 2: สร้างตารางและล็อกสิทธิ์ (RLS)
1. ไปที่เมนู **SQL Editor** → กด **New query**
2. คัดลอกโค้ดทั้งหมดจากไฟล์ `supabase-schema.sql` มาวางแล้วกด **Run**

### ขั้นที่ 3: สร้างบัญชีของคุณคนเดียว & ปิดไม่ให้คนอื่นสมัคร
1. ไปที่ **Authentication → Users** → กด **Add user → Create new user**
   - ใส่อีเมลและรหัสผ่านที่คุณจะใช้เข้าเว็บ
   - ติ๊กถูก **Auto Confirm User** แล้วกดสร้าง
2. ไปที่ **Authentication → Sign In / Providers** (หรือ Settings)
   - **ปิดสวิตช์ `Allow new users to sign up`** เพื่อให้มีเพียงบัญชีของคุณคนเดียวเท่านั้นที่เข้าสู่ระบบได้

### ขั้นที่ 4: นำ Key มาใส่ใน `config.js`
1. ไปที่ **Project Settings → API**
2. คัดลอก **Project URL** และ **anon / public key**
3. เปิดไฟล์ `config.js` แล้ววางลงใน 2 บรรทัดนี้:
   ```js
   SUPABASE_URL: 'https://xxxxxxxx.supabase.co',
   SUPABASE_ANON_KEY: 'eyJhbGciOiJIUzI1NiIsInR5cCI6...',
   ```
   *(หมายเหตุ: `anon key` ถูกออกแบบมาให้ใช้ฝั่งหน้าเว็บได้ปลอดภัยตราบใดที่เปิด RLS ในขั้นที่ 2 และปิด Signup ในขั้นที่ 3)*

## วิธีเอาขึ้น GitHub Pages (ฟรี เปิดจากมือถือ/คอมที่ไหนก็ได้)

โปรเจกต์นี้เป็นเว็บ Static ล้วน (ไม่ต้อง build) อัพขึ้น GitHub แล้วใช้งานได้ทันที:

1. สร้าง Repository ใหม่บน GitHub (เช่นชื่อ `my-study-tracker`)
2. อัพโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น Repo (หรือใช้คำสั่ง `git init`, `git add .`, `git commit`, `git push`)
3. เข้าไปที่หน้า Repo บน GitHub → **Settings → Pages**
4. ตรงหัวข้อ **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: `main` / `/ (root)` → กด **Save**
5. รอประมาณ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อรีโป>/` ไว้เปิดใช้งานส่วนตัวได้ทันที!
